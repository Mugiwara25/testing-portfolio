API Test Examples

GET Requests

GET All Posts

Endpoint: GET https://jsonplaceholder.typicode.com/posts

Tests:

  • ✓ Status code is 200
  • ✓ Response time is less than 500ms
  • ✓ Response body contains array of posts
  • ✓ Each post has required fields (id, title, body, userId)

POST Requests

POST Create New Post

Endpoint: POST https://jsonplaceholder.typicode.com/posts

Test Data:

{
  "title": "Test Post",
  "body": "This is a test post",
  "userId": 1
}

Tests:

  • ✓ Status code is 201 (Created)
  • ✓ Response contains generated ID
  • ✓ Response matches request data

PUT & DELETE Requests

PUT Update Post

Endpoint: PUT https://jsonplaceholder.typicode.com/posts/1

Tests:

  • ✓ Status code is 200
  • ✓ Updated data reflects in response
  • ✓ All fields present in response

DELETE Post

Endpoint: DELETE https://jsonplaceholder.typicode.com/posts/1

Tests:

  • ✓ Status code is 200
  • ✓ Response is empty object
  • ✓ Fast response time (<500ms)

Negative Testing

GET Non-existent Resource (404 Error)

Endpoint: GET https://jsonplaceholder.typicode.com/posts/99999

Tests:

  • ✓ Status code is 404
  • ✓ Response is empty object
  • ✓ Error response is fast
