Bug Report #1: Login Page - Security Issue

Bug ID: BUG-LOGIN-001

Title: Password visible in page source

Severity: High

Priority: High

Environment: Chrome 120, Windows 11

Steps to Reproduce:

  1. Navigate to login page
  2. Enter any username and password
  3. Right-click → View Page Source
  4. Search for "password" in source code

Expected Result: Password should not be visible in page source

Actual Result: Password appears in plain text in HTML source

Attachment: screenshot_source_code.png

Bug Report #2: Search Functionality - Data Issue

Bug ID: BUG-SEARCH-001

Title: Search returns incorrect results for special characters

Severity: Medium

Priority: Medium

Environment: Firefox 119, macOS

Steps to Reproduce:

  1. Go to product search page
  2. Enter search term: "C++ programming"
  3. Click search button

Expected Result: Returns relevant C++ programming books

Actual Result: Returns all products (ignores special characters)

Attachment: search_results_screenshot.png

Bug Report #3: UI Responsiveness Issue

Bug ID: BUG-UI-001

Title: Navigation menu overlaps content on mobile view

Severity: Low

Priority: Low

Environment: Safari, iPhone 12

Steps to Reproduce:

  1. Open website on mobile device
  2. Click on menu button
  3. Scroll down the page

Expected Result: Menu should collapse properly

Actual Result: Menu stays open and overlaps page content

Attachment: mobile_screenshot.png
