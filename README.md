# 🧪 QA Engineering Portfolio

A professional portfolio showcasing manual testing documentation, test cases, bug reports, and testing methodologies.

## 🚀 Live Demo
[View Portfolio](https://Mugiwara25.github.io/testing-portfolio)

## 📋 Features
- **Test Case Documentation** - Sample test cases for login functionality
- **Bug Reports** - Professional bug reporting templates  
- **Testing Checklists** - Comprehensive checklists for different scenarios
- **Testing Methodology** - Systematic approach to software quality assurance
- **Interactive Elements** - Toggle checklists, print/export functionality

## 🛠️ Technologies Used
- HTML5
- CSS3 (with Flexbox/Grid)
- JavaScript (Vanilla)
- GitHub Pages (Hosting)

## 🎯 Pages Overview

### 1. Home Page
Overview of portfolio features and testing skills demonstrated.

### 2. Methodology Page
7-step testing methodology covering requirement analysis to test closure.

### 3. Test Cases Page
8 detailed test cases for login functionality with pass/fail status.

### 4. Bug Reports Page
3 sample bug reports following industry standards with templates.

### 5. Checklists Page
Comprehensive checklists for web application, login, and regression testing.

## 🔧 Interactive Features
- Toggle checklist items with visual feedback
- "Toggle All" buttons for each checklist section  
- Print/Export test cases to PDF
- Test statistics counter
- Responsive design for all devices
